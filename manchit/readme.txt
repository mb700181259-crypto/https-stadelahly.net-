قالب أخبار ووردبريس فائق السرعة، مُحسّن بالكامل لسيو جوجل نيوز واكتشاف جوجل (Discover) واقتراحات جوجل.

== الوصف ==

Manchit (مانشيت) قالب أخبار عربي احترافي بُني من الصفر ليكون:

* الأسرع: CSS/JS خفيف بلا jQuery في الواجهة، تحميل خطوط بـ display:swap و preload، تحسين LCP و CLS، إزالة أكواد ووردبريس الزائدة، دعم lazy-load للصور و iframes.
* الأقوى في السيو: بيانات منظمة كاملة (NewsArticle / NewsMediaOrganization / WebSite + صندوق بحث Sitelinks / BreadcrumbList / Speakable)، وسوم Open Graph و Twitter Cards، وتوجيه max-image-preview:large الضروري لظهور الصور في Google Discover.
* الأجمل: تجربة قراءة بصرية آسرة، وضع ليلي/نهاري، شريط تقدم القراءة، جدول محتويات تلقائي، أزرار مشاركة، شريط أخبار عاجلة، وتصميم عربي RTL أنيق.
* الأذكى في الإعلانات: نظام إدارة إعلانات بمواضع متعددة وحقن داخل المقال — و‏١٠٠٪ من الأرباح لك (لا يحقن القالب أي إعلانات لصالح المطوّر ولا يأخذ نسبة).

== المميزات ==

= الأداء والسرعة =
* بدون jQuery في الواجهة الأمامية.
* CSS مبني بخصائص منطقية (Logical Properties) — ملف واحد يعمل RTL و LTR.
* Critical CSS مضمّن، وتحميل الخطوط بلا حجب للعرض.
* fetchpriority=high على صورة الـ LCP، وnative lazy-loading لبقية الصور والـ iframes.
* إزالة الإيموجي، وروابط RSD/WLW، ومولّد ووردبريس، وتقليل REST/oEmbed.

= السيو وجوجل نيوز/ديسكفري =
* Schema بصيغة JSON-LD @graph: NewsArticle، NewsMediaOrganization، WebSite (مع SearchAction)، BreadcrumbList، Speakable.
* Open Graph + Twitter Cards (صورة كبيرة 1200×630 للاكتشاف والمشاركة).
* max-image-preview:large + max-snippet:-1.
* عناوين Schema مقصوصة على 110 حرفًا حسب توصيات جوجل.
* يتوقّف تلقائيًا عن إخراج السكيمة/الميتا عند وجود Rank Math أو Yoast لتفادي التكرار.

= المقال =
* صورة بارزة، تصنيفات، ميتا (كاتب/تاريخ/زمن قراءة/مشاهدات)، وسوم، صندوق كاتب.
* جدول محتويات تلقائي مع تتبّع القسم النشط.
* أزرار مشاركة (فيسبوك، X، واتساب، تيليجرام، نسخ الرابط + مشاركة النظام).
* مقالات ذات صلة، تنقل بين المقالات، تعليقات متداخلة.
* عدّاد مشاهدات خفيف يعمل مع الكاش (REST ping).

= الإعلانات =
* مواضع: أسفل الهيدر، قبل/بعد المقال، بعد العنوان، داخل المقال بعد فقرة محددة، الشريط الجانبي، قبل التذييل، شريط ثابت أسفل الشاشة.
* استهداف الأجهزة (جوال/سطح مكتب)، تفعيل/تعطيل كل وحدة، إخفاء عن الأعضاء.
* شورت كود [manchit_ad location="..."].

= التحكم =
* لوحة تحكم كاملة: المظهر ← إعدادات Manchit (عام، خطوط، تخطيط، مقالات، سيو، إعلانات، تواصل).
* تكامل مع أداة التخصيص (Customizer) لمعاينة الألوان مباشرة.
* خطوط عربية: Cairo، Tajawal، Noto Kufi Arabic، IBM Plex Sans Arabic، Readex Pro، أو خط النظام.

== التثبيت ==

1. ارفع مجلد `manchit` إلى `wp-content/themes/` (أو ارفع ملف zip من: المظهر ← القوالب ← أضف جديد ← رفع).
2. فعّل القالب من: المظهر ← القوالب.
3. اضبط الإعدادات من: المظهر ← إعدادات Manchit.
4. أنشئ القوائم من: المظهر ← القوائم (موقع "القائمة الرئيسية").
5. أضف الودجات من: المظهر ← الودجات.

== الأسئلة الشائعة ==

= هل يحتاج إضافة سيو؟ =
لا. القالب يخرج البيانات المنظمة و Open Graph بنفسه. وإن كانت لديك Rank Math أو Yoast، يتوقف القالب تلقائيًا عن التكرار ويترك الأمر للإضافة.

= هل يعمل مع AMP؟ =
البنية نظيفة ومتوافقة. يُنصح باستخدام إضافة AMP الرسمية عند الحاجة.

= هل يأخذ القالب نسبة من أرباح الإعلانات؟ =
لا إطلاقًا. ‏١٠٠٪ من الأرباح لك.
