قالب ابن لـ arbah يضيف سيو أخبار كامل وتحسينات سرعة ووضع ليلي — دون تعديل القالب الأصلي.

== الوصف ==

هذا **قالب ابن (Child Theme)** يعمل فوق قالب arbah الأصلي. الغرض منه إضافة ما ينقص arbah
دون لمس ملفاته، فتبقى تحديثات القالب من المطوّر سليمة، وتبقى تحسيناتك محفوظة.

**متطلّب أساسي:** يجب أن يكون قالب arbah (الأصلي) مثبّتاً على الموقع. فعّل «arbah Pro» بدلاً منه.

== ما يضيفه ==

= سيو الأخبار (يتوقف تلقائياً عند وجود Rank Math / Yoast / SEOPress / AIOSEO) =
* بيانات JSON-LD @graph: NewsArticle (للمقالات) + NewsMediaOrganization + WebSite مع صندوق بحث Sitelinks + BreadcrumbList + ImageObject.
* وسوم Open Graph و Twitter Cards كاملة (عنوان/وصف/صورة بأبعاد/قسم/وسوم/تواريخ النشر والتعديل).
* توجيه max-image-preview:large + max-snippet:-1 (شرط ظهور الصور في Google Discover).
* خريطة أخبار XML على /news-sitemap.xml (مقالات آخر 48 ساعة — نافذة Google News).

= السرعة (تحسينات آمنة لا تكسر التصميم) =
* تنظيف الهيدر: إزالة RSD/WLW/مولّد ووردبريس/الرابط المختصر/الإيموجي.
* إزالة jQuery Migrate من الواجهة.
* preconnect لخوادم الخطوط + إضافة display=swap لخطوط جوجل (يمنع حجب النص).
* preload وfetchpriority=high لصورة المقال (LCP) لتحميلها أولاً.

= تجربة القراءة =
* وضع ليلي اختياري (زر عائم، محفوظ محلياً) — لا يفرض نفسه على الزائر.
* شريط تقدّم القراءة في صفحات المقالات.
* زر «العودة للأعلى».

== ملاحظات ==

* لم تُعدَّل أي ثغرة داخل القالب الأصلي (arbah) لأن القالب الابن لا يلمس ملفات الأصل؛ ملاحظة `$_POST` الصغيرة في arbah غير ضارّة (القيمة تُعقَّم) ويمكن معالجتها في تحديث للأصل عند الحاجة.
* لم تُضَف خطوط عربية للواجهة RTL كي تبقى الأسرع (خطوط النظام) — يمكن تفعيل خط ويب عند الطلب.
* كل ميزة قابلة للإيقاف عبر فلاتر (arbah_pro_enable_ux، arbah_pro_seo_active، arbah_pro_preload_lcp، ...).
